# Laboratorio de prompts (Streamlit)

Compara las estrategias zero-shot, one-shot y few-shot del Asesor de Imagen usando el backend de Spring Boot.

```bash
pip install -r requirements.txt
BARBERIA_API_URL=http://localhost:8080 streamlit run app.py
```

Con Docker: `docker compose --profile ia up -d` y abre http://localhost:8501.
Documentación: [docs/U2-ia](../../docs/U2-ia/README.md).
